# 物理計算の修正結果（2026-09-08）

[監査](reports/physics-audit-2026-09-08.md)で確認した現行機能10件と未使用ヘルパー2件、計12件を修正した。監査の閾値を緩めることなく **32/32項目成功**、既存13件と追加回帰10件の **Pythonテスト23/23件成功**。その後の指示でyoshimulib本体にも修正を適用し、ライブラリの追加テスト **7/7件成功**を確認した。

## 修正内容

| 監査番号 | 修正 |
|---|---|
| 1 円・赤道軌道の位相 | yoshimulib本体の`oe2rv()`でω・Ωを無条件に消す処理を削除し、元の全回転角を適用。mRenderingの暫定アダプターを削除し、修正済み関数を直接利用。CSV・Kepler・数値伝播の初期値・groundobsの一括天頂合わせで有効。円・順行赤道・逆行赤道と各閾値の近傍で独立参照との一致を確認。 |
| 2 relativeのCSV姿勢 | `attitude_at()`のBody→ECI行列を転置してECI→Bodyとして返す。RTNへ変換した最終モデル姿勢まで回帰テスト。 |
| 3 負時刻の数値軌道 | 正方向・逆方向を別々に積分し、有効時刻区間と補間解を保持。正負の時刻が混ざる問い合わせ・区間延長・非有限値の拒否を検証。 |
| 4 地球のUV | 地表・雲・夜光に共通の180°UV原点補正を適用。地理経度0°と+Xを揃え、自転後も3層が同じ地点を表すことを実交差UVで確認。 |
| 5 CSV姿勢未指定 | CSVに姿勢がない場合はr,vと指定のnadir / sun_tracking / velocity_alignedで姿勢を計算。 |
| 6 姿勢積分 | yoshimulibの`q_kine()`とEuler方程式をDOP853で連立積分。qとωの双方に誤差制御を適用。substepsは最大積分刻みの制限として維持。ゼロ時間・ゼロ角速度・逆向き積分も対応。 |
| 7 遮蔽誤判定 | 地表接触に数値スケールに応じた浮動小数点許容差を設定。天頂と地平線接触を可視、地平線直下を遮蔽として検証。 |
| 8 地表追尾と自転 | 搭載カメラの地表ターゲットを同じ自転角で回転。バッチ・ライブ・ターゲットで自転角の計算を共通化。 |
| 9 パネルの受光軸 | 軌道描画の手続き生成パネルをXY面に配置し、法線±Zをsun_trackingの+Z指向に一致させた。外部モデルの姿勢規約は維持。 |
| 10 MLI材質 | 拡散側weightを0.3に修正し、宣言どおり鏡面70%・拡散30%とした。 |
| 11 大気透過率 | 光学的厚さに対する散乱係数の二重掛けを除去。太陽側も波長別係数を1回だけ適用。 |
| 12 地球アルベド | 可視地球面の外向き法線として地球→衛星方向を使い、昼夜判定を修正。 |

`yoshimulib`は`yoshimulib`へのシンボリックリンク。ユーザーの追加指示により、共有ライブラリの[orbit/orbital_elements.py](yoshimulib/orbit/orbital_elements.py)を直接修正し、[ライブラリ回帰テスト](yoshimulib/tests/test_orbital_elements.py)を追加した。mRenderingの暫定補正は削除済み。同じライブラリを利用する他プロジェクトにも修正が反映される。他環境へ変更を移す場合は両リポジトリの変更を揃える必要がある。
